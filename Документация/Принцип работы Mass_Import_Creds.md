# Принцип работы Mass_Import_Creds

MassImportCreds - это плагин, отвечающий за множественное добавление учётных данных на данный проект. Этот плагин полезен, в первую очередь, при компрометации какой-либо базы данных, содержащей
хэши паролей, их восстановлении и добавлении к проекту.

Импорт реализован в качестве *action_module* с целью его выполнения в фоновом режиме - учётных данных может быть много, останавливать на время импорта работу веб-панели не является хорошим решением.

Работает импорт следующим образом:
Получает либо файл, либо набор строк, содержащих данные импорта. Каждый элемент (будущий объект Credential) находится на своей строке. Задаётся разделитель в соответствующем поле, а также индексы столбцов,
в которых будут находиться соответствующие данные. Строки разбиваются строго по заданному разделителю, после чего соответствующие столбцы подставляются в соответствующие позиции в объект
Credential.

Правила подстановки следующие:
- Если комбинация логин/пароль или хэш/тип хэша уже существует в БД - то берётся существующий объект, для которого производится обновление поля "Источник компрометации".
- Если комбинация логин/пароль/администратор или логин/хэш пароля/тип хэша/администратор уже существует в БД - то берётся существующий объект, и для него обновляется поле "Связанные службы".
- Если комбинация хэш/тип хэша в исходных данных уже существует в БД, и при этом для них представлен пароль - то берётся существующий объект, для него обновляется пароль, а также выставляется параметр "Проверен на словаре", но только если ранее этот параметр не был выставлен.
- Если же комбинация логин/пароль/администратор или логин/хэш пароля/тип хэша/администратор - не существует, то добавляется новый объект учётных данных, для которого проставляются все соответствующие параметры.
- Также если представлен только хэш пароля/тип хэша без логина, и этот хэш уже есть в БД - добавляться новый хэш не будет.

Если строка представляет из себя значение $HEX[abcabc] (т.е. формат HashCat), то в качестве значения поля будет подставлено раскодированное значение
